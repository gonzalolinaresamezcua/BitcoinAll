# Security Policy

BitcoinAll Core — reportes de seguridad solo vía GitHub.

## Reportar vulnerabilidades

Abre un [issue privado de seguridad](https://github.com/gonzalolinaresamezcua/BitcoinAll/security/advisories/new) o contacta a los mantenedores por GitHub. No hay web ni correo oficial del proyecto.
